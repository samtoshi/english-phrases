# 英語フレーズ

日本語 → 英語のフレーズ練習アプリ（個人用）。忘れかけたころにもう一度出す間隔反復（SM-2）、英語の読み上げ（en-US）、
音声認識で答える・3回リピート、5問ずつのセットで進みます。

**このリポジトリにはフレーズのデータは入っていません。** アプリにはオリジナルのサンプル（会議・仕事の英語 8問）だけが入っています。
練習したいフレーズは、端末で「設定 → ファイルから読み込む」から JSON / CSV を読み込みます。データ・記録は端末の中（localStorage）に保存されます。

## クラウド同期（任意）

「設定 → Google でログイン」すると、フレーズ（読み込んだもの・自分で追加したもの）と覚えぐあいが Firestore に保存され、別の端末でも同じ記録で続けられます。
あんきカード（anki-app）と同じ Firebase プロジェクトを使い、場所は `phrasebook/{uid}/data/state` と `phrasebook/{uid}/cards/b0〜b7` だけ。
Firestore のルールで、登録したアカウント本人（Google ログイン・uid 一致）だけが読み書きできます（ルールはこのリポジトリには入れていません）。
ログインしなくても、オフラインでも、この端末だけでそのまま使えます。変えたものは、つながったときに「新しい方を残す」形でまとめます。

## 使い方

- 今日の復習（期限がきた復習＋新しいフレーズ。新しいフレーズは1日10問・設定で変更可）／ランダム／レッスンをえらぶ／苦手だけ
- 日本語（と場面のヒント）を見て、英語を入力するか 🎤 で話す → 答え合わせ
  - 大文字小文字・記号・短縮形（I'm = I am など）の違いは同じとみなし、ほぼ同じなら「ほぼ正解」。ちがう語は色で表示
  - お手本を英語で読み上げ（🔊 でもう一度）。自分で採点（もう一回／難しい／言えた／簡単）
- 3回リピート：お手本を声に出して3回（🎤 で確認、または「言えた」をタップ）。3回目でマスター
- 5問ごとに「続けますか？」、5セット（25問）ごとにもう一度確認
- 進み具合：覚えた数・練習中・3回リピート済み・連続日数・これからの復習・レッスンごと
- フレーズの追加・編集・削除、バックアップ（JSON）の書き出し・復元
- ホーム画面に追加して、オフラインでも使えます

## 読み込めるファイル

- JSON：`[{ "id": 1, "lesson": "Lesson 1", "theme": "…", "japanese": "…", "english": "…", "note": "…" }, …]`（`japanese` と `english` だけでも可。`{ "items": [...] }` も可）
- CSV / TSV：見出しに `japanese,english`（`日本語,英語` でも可。任意で `lesson, theme, note, id`）。見出しがなければ 1列目＝日本語・2列目＝英語
- `note` を `[会議の冒頭で]` のように [ ] でかこむと、答える前に出る場面のヒントになります（それ以外は答えのあとに出る解説）
- 同じ `id`（id がなければ同じ文）のフレーズは上書きされ、覚えぐあいは残ります

## 開発

ビルド不要の静的サイト（HTML / CSS / JavaScript モジュール）。あんきカード（anki-app）の SM-2 と、iPad / iPhone 向けに対策した読み上げ（js/voice.js）を英語用にして使っています。

```sh
python3 -m http.server   # http://localhost:8000
npm test
```

| ファイル | 役割 |
|---|---|
| `js/app.js` | 画面 |
| `js/srs.js` | 復習スケジュール（SM-2） |
| `js/session.js` | モードごとの出題リスト・5問ずつのセット |
| `js/match.js` | ゆるい答え合わせ・単語の差分 |
| `js/data.js` | JSON / CSV の読み込み・サンプル |
| `js/store.js` | 端末の中の記録・バックアップ |
| `js/merge.js` / `js/cloudsync.js` | 端末とクラウドの記録をまぜる（新しい方を残す）・同期の手順 |
| `js/cloud.js` / `js/firebase-config.js` | Firebase（Google ログイン・Firestore）。SDK はログインしたときだけ読みこむ |
| `js/voice.js` | 英語の読み上げ・音声認識 |

アプリ本体のファイルを変えたときは `sw.js` の `VERSION` を上げてください。
